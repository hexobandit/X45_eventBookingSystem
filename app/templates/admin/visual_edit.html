💡 How to write a good course page (tips + AI prompt to copy)
  • Title — short and concrete (max ~60 characters), no marketing fluff.
  • Short description — plain text, max 300 characters; this is what shows on the course card.
  • Description — 3–5 short paragraphs; paste from Word/Docs is fine, formatting is cleaned automatically.
  • Program — day-by-day bullet lists; What you'll learn — 5–8 bullets, each starting with a verb.
  • Image — landscape, at least 1600px wide; adjust crop with the position slider.
